# Personal Assistant

Консольний персональний помічник на Python для управління контактами, телефонними номерами, електронною поштою, адресами, днями народження та нотатками.

Застосунок дозволяє зберігати контактну інформацію, редагувати та шукати записи, отримувати список найближчих днів народження, створювати нотатки, організовувати їх за тегами та здійснювати пошук потрібної інформації.

Дані зберігаються локально на комп'ютері користувача, що дозволяє продовжувати роботу після повторного запуску застосунку.

## Можливості

- Додавання нових контактів.

- Пошук контактів за електронною поштою.

## Структура проєкту

```text
PersonalAssistant/
│
├── pyproject.toml
├── README.md
│
├── data/
│   ├── addressbook.pkl
│   └── notes.pkl
│
└── cli_bot/
    ├── __init__.py
    ├── __main__.py
    ├── main.py
    ├── parser.py
    ├── models.py
    ├── address_book.py
    ├── note_book.py
    ├── storage.py
    ├── handlers.py
    └── help_text.py
```

### Опис файлів

| Файл | Призначення |
|---|---|
| `pyproject.toml` | Конфігурація проєкту та залежностей Poetry |
| `README.md` | Документація та інструкція користувача |
| `__init__.py` | Ініціалізація Python-пакета |
| `__main__.py` | Точка запуску застосунку як модуля |
| `main.py` | Основний цикл роботи застосунку та маршрутизація команд |
| `parser.py` | Розбір введених користувачем команд |
| `models.py` | Моделі даних контактів та їх полів |
| `address_book.py` | Логіка роботи з контактами |
| `note_book.py` | Логіка роботи з нотатками та тегами |
| `storage.py` | Збереження та завантаження даних |
| `handlers.py` | Обробники команд користувача |
| `help_text.py` | Довідка та опис доступних команд |

### Папка data

Папка `data` призначена для зберігання інформації користувача.

```text
data/
├── addressbook.pkl
└── notes.pkl
```

- `addressbook.pkl` — файл із контактами.
- `notes.pkl` — файл із нотатками.

Папка `data` створюється автоматично при першому збереженні даних, якщо вона ще не існує.

## Вимоги

Для роботи застосунку необхідно встановити:

- Python 3.10 або новішої версії.
- Poetry.
- Git (необов'язково, якщо проєкт уже знаходиться на комп'ютері).

Рекомендується використовувати Visual Studio Code для роботи з проєктом.

---

## Встановлення

### 1. Перевірка Python

Відкрийте термінал PowerShell або Terminal у Visual Studio Code.

Перевірте версію Python:

```powershell
python --version
```

Якщо команда `python` не працює, спробуйте:

```powershell
py --version
```

Якщо Python не встановлений, завантажте його з офіційного сайту:

https://www.python.org/downloads/

Під час встановлення Windows рекомендується увімкнути опцію:

`Add Python to PATH`

---

### 2. Встановлення Poetry

Перевірте, чи встановлений Poetry:

```powershell
poetry --version
```

Якщо Poetry не встановлений, встановіть його відповідно до офіційної документації:

https://python-poetry.org/docs/#installation

Після встановлення перевірте:

```powershell
poetry --version
```

---

### 3. Відкриття проєкту

Перейдіть до папки проєкту:

```powershell
cd PersonalAssistant
```

Якщо проєкт знаходиться в іншій директорії, використовуйте відповідний шлях.

---

### 4. Встановлення залежностей

У кореневій папці проєкту виконайте:

```powershell
poetry install
```

Poetry автоматично:

- створить віртуальне середовище, якщо воно ще не існує;
- встановить залежності, визначені у `pyproject.toml`;
- підготує середовище для запуску застосунку.

## Запуск застосунку

Для запуску Personal Assistant виконайте команду:

```powershell
poetry run python -m cli_bot
```

Після запуску з'явиться привітання та запрошення до введення команди.

```text
Вітаю! Я ваш персональний помічник.
Введіть команду або help для перегляду доступних команд.
```

Для отримання довідки введіть:

```text
help
```

Для перегляду повного списку доступних команд введіть:

```text

```

## Збереження даних

Personal Assistant використовує локальне збереження даних за допомогою `pickle`.

Під час роботи дані зберігаються у відповідних структурах:

- `AddressBook` — контакти.
- `NoteBook` — нотатки.

При завершенні роботи застосунку дані записуються у файли:

```text
data/
├── addressbook.pkl
└── notes.pkl
```

Під час наступного запуску дані автоматично завантажуються.

### Важливо

Не видаляйте папку `Data`, якщо хочете зберегти контакти та нотатки.

Рекомендується періодично створювати резервну копію папки `Data`.

## Обробка помилок

Застосунок обробляє типові помилки користувача:

- неправильний формат телефонного номера;
- некоректний формат електронної пошти;
- неправильний формат дати народження;
- відсутність контакту;
- відсутність нотатки;
- неправильна кількість аргументів команди;
- невідома команда;
- помилки завантаження збережених даних.

При виникненні помилки застосунок повідомляє користувача про проблему та дозволяє продовжити роботу.

## Завершення роботи

Для завершення роботи застосунку введіть одну з команд:

```text
exit
```

або

```text
close
```

або

```text
quit
```

Після завершення роботи дані зберігаються, щоб їх можна було використовувати під час наступного запуску.
